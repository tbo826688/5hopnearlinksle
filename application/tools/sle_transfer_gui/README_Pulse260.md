# 260峰值排空版

该版本保留原有协议和文件校验，只改变电脑向 Node1 写入数据的节奏。

- 活动发送阶段固定使用界面设置的峰值速率，默认 260 kbps。
- 每轮初始发送 4 个 900 字节数据包，然后至少暂停 400 ms。
- 若 Node1 空闲缓冲不足或未确认包较多，自动缩短发送批次并将暂停时间增加到 1.2 s。
- 有缓冲反馈时，必须连续收到两次恢复状态才开始下一轮发送。
- 界面最终显示活动时段速率，同时在日志中显示包含停发时间的全程平均速率和占空比。

活动时段速率与全程平均速率不是同一个指标。只要存在停发排空，全程平均速率必然低于活动发送速率。

编译命令：

```powershell
pyinstaller --clean --noconfirm SLE-5Hop-Transfer-Pulse260.spec
```

输出文件：

`dist/SLE-5Hop-Transfer-Pulse260.exe`
